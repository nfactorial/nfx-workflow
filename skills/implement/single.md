# One change

Read by `SKILL.md` for a spec path or a folder, with or without a change name: the
single-change procedure, steps 0 to 8, run in order. Read `build-loop.md`
now and run its steps 0 to 6, then step 7 below, then its step 8. What `build-loop.md` raises
comes to the user: ask or tell the user. When step 0 raises that CLAUDE.md names no checks,
ask the user for the commands to run: their answer is the checks for this run, and offer to add
it to the project's CLAUDE.md as the checks to run before a commit, writing it only once the
user agrees.

7. **Report.** Read `<skill folder>/report.md` and report as it says, to the end of its
   next steps.
